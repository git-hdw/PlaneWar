# 像素飞机大战 —— 游戏开发面试 Demo 测试题

> **岗位方向**：游戏开发（客户端）
> **任务性质**：独立完成一款可运行的「像素飞机大战」竖版空战 Demo

---

## 🎯 游戏概述

- **游戏类型**：竖版像素风飞机空战（视角自下而上，主角在底部，敌人从上方来袭）
- **核心目标**：操控主角飞机消灭来袭敌人，在有限生命下尽可能存活并获取高分
- **核心内容**：本 Demo 需要实现**主角与敌人的攻击/受击逻辑**，以及**完整的游戏流程（开始 → 进行 → 暂停 → 结束）**

## ✈️ 主角设定（面试者需实现）

- **外观**：像素风格主战机，机头装有发射口（朝上方）
- **操控**：支持移动（触屏拖动），可向上发射子弹攻击敌人
- **生命**：初始拥有若干生命（建议 3 条），被敌人或敌弹命中扣 1 条生命
- **自动/手动射击**：需实现主角的攻击逻辑，子弹向上发射

---

## 🎮 战斗系统：攻击与受击逻辑

### 1. 主角飞机的攻击

- 发射子弹向**上**攻击敌人
- 子弹与敌人发生碰撞即判定命中，触发敌人受击逻辑
- 需保证射击节奏合理、命中判定准确

### 2. 两类敌人的攻击与受击

游戏需包含以下**两类敌人**，且面试者必须分别实现它们的**攻击逻辑**与**受击逻辑**：

#### 坦克类敌人（地面/重型单位）
- **特征**：血厚、移动慢或固定，作为重型障碍
- **攻击方式**：缓慢发射炮弹 / 或周期性强力攻击（面试者自行设计具体攻击形态）
- **受击逻辑**：被主角子弹命中后扣血，血量归零销毁；需有受击反馈（闪烁、缩放、击退、爆炸特效等）

#### 飞机类敌人（空中单位）
- **特征**：灵活、可移动，从屏幕上方进入并向下袭来
- **攻击方式**：发射子弹向下攻击主角飞机（需实现敌弹生成与命中主角判定）
- **受击逻辑**：被主角子弹命中后扣血/或直接销毁；需有受击反馈

### 3. 碰撞与受伤规则

- 主角飞机被敌弹或敌机撞击 → 扣 1 生命
- 生命归零 → 触发游戏结束
- 护盾激活期间主角无敌（详见道具）

## 🔄 游戏流程（面试者必须完整实现）

必须包含以下完整状态流转，且各状态可正确切换：

1. **开始游戏（Start）**
   - 展示开始界面（标题、开始按钮）
   - 点击开始 → 进入游戏进行态，初始化主角、敌人、分数、生命

2. **游戏进行（Playing）**
   - 主角可操控、可攻击
   - 敌人按规则生成并攻击
   - 道具按规则生成并可拾取
   - 实时显示：分数、生命数

3. **游戏暂停（Pause）**
   - 提供暂停按钮 / 暂停入口
   - 暂停后：游戏逻辑停止（敌人、子弹、计时全部冻结），显示暂停界面（继续 / 重开）
   - 继续后：从暂停点无缝恢复

4. **游戏结束（Game Over）**
   - 触发条件：主角生命归零
   - 展示结束界面：最终分数、最高分（可选）、重新开始按钮
   - 点击重开 → 回到开始 / 重新开始一局

## 📊 计分与胜利条件

- **得分系统**：每消灭一个敌人获得固定分数；游戏中实时刷新分数
- **失败条件**：主角生命归零
- **胜利条件**：无明确终点，以获得高分为目标，考验玩家极限

---

## ✨ 设计要求

1. **逻辑正确优先**：四类攻击/受击（主角、坦克敌、飞机敌、道具生效）必须闭环且正确
2. **效果加分**：使用缓动（Tween/Easing）让飞机、敌机、子弹、爆炸等表现更动态；敌人受击要有清晰反馈
3. **UI 一目了然**：分数、生命、护盾倒计时、暂停/开始按钮清晰直观，排版醒目
4. **素材运用**：优先使用给定美术素材，也可自行添加新素材增强表现
5. **操作手感**：操控与射击响应灵敏、连贯顺畅
6. **稳定性**：运行稳定，无卡死、崩溃等致命 Bug；暂停/继续、重开流程切换无残留状态
