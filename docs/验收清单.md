## 安装和操作

- [ ] APK 可在支持 ARM64 应用、Android API 25 或更高版本的设备安装和启动。
- [ ] 游戏以竖屏运行，开始界面文字、按钮显示正常。
- [ ] 点击开始后，初始分数为 0、生命为 3。
- [ ] 触屏拖动响应正常，飞机不会离开移动边界。
- [ ] 点击 UI 按钮时，飞机不会跟随该触点移动。
- [ ] 刘海 / 挖孔屏及系统导航区域不会遮挡分数、生命或暂停按钮。

## 战斗与道具

- [ ] 玩家子弹向上发射，命中敌人可造成伤害。
- [ ] 飞机敌人从上方出现、移动并向下射击。
- [ ] 坦克敌人耐久更高，周期性向玩家发射炮弹。
- [ ] 敌人受击和被击败时反馈可见。
- [ ] 敌弹或敌机撞击玩家扣 1 生命，受伤后的短暂无敌有效。
- [ ] 击败飞机得 100 分，击败坦克得 300 分，HUD 及时更新。
- [ ] 生命道具增加 1 生命，上限为 6。
- [ ] 护盾道具提供 3 秒无敌，倒计时和结束效果正常。
- [ ] 炸弹道具清除当前敌人和敌方子弹。

## 流程和稳定性

- [ ] 暂停后，敌人、子弹、道具、射击计时和护盾倒计时停止。
- [ ] 点击继续后，从原状态恢复。
- [ ] 暂停界面点击重开，恢复 3 生命、0 分，无上一局敌人残留。
- [ ] 生命归零后显示结束界面、最终分数和最高分。
- [ ] 结束后重开正常，连续重开多次无异常。
- [ ] 退出并重新启动应用，最高分正确保留。
- [ ] 切换到后台再返回，确认游戏和音频状态符合预期。
- [ ] 连续游玩至少 10 分钟，无卡死、崩溃或明显异常。
